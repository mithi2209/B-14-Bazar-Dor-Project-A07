 
# My Project : BazarDor
 ### BazarDor is a modern and responsive web application that helps users easily view and track daily market prices of essential products in Bangladesh.
 

 ## Technologies I have Used :

 - **Next.js** – React framework for building the application .

 - **TypeScript** – Type-safe and maintainable code .

 - **Tailwind CSS** – Responsive and utility-first styling .

 - **Better Auth** – For User authentication .
 - **React Hot Toast** – To Show Success and error notifications .

 ## 5 key features of my project :

### 1.  Price Change Tracking – 
    Easily identify products with rising or falling prices.

 

 ### 2. Daily Market Prices – 
    Showing current prices of essential products. 


 ### 3. Category & Product Details – 
    Browse products by category and view detailed market-wise prices.

 ### 4.Secure Authentication  – 
    Sign up and sign in with email/password and social login with google or github.

 ### 5. Fully Responsive Design  – 
    Works smoothly on mobile, tablet, and desktop devices.
